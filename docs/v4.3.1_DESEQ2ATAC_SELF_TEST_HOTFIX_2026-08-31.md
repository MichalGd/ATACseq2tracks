# ATACseq2tracks v4.3.1 DESeq2ATAC self-test hotfix

## Scope

Version 4.3.1 corrects a release-blocking error in the synthetic DESeq2ATAC
self-test shipped with v4.3.0. It does not change production differential
accessibility analysis or any workflow output.

## Cause

The v4.3.0 self-test applied `pmax(1L, no_effect)` to a count matrix. Because
the scalar first argument did not carry matrix attributes, the result could
lose its dimensions. The subsequent `colnames()` assignment then failed with:

```text
attempt to set 'colnames' on an object with less than two dimensions
```

## Correction

The test now:

- applies the lower bound by matrix subassignment, preserving dimensions;
- explicitly verifies the expected matrix shape;
- mirrors the two synthetic replicates between conditions for the no-effect
  case, making the expected zero-significant result deterministic;
- retains a separate strong-effect case to verify detection of differential
  accessibility.

No production command-line path calls `run_synthetic_self_test()` unless the R
script is invoked explicitly with `--self-test`.

## Compatibility

All v4.3.0 operational behavior and all v4.2.0 scientific behavior are retained.
Existing v4.2.0 and v4.3.0 analysis outputs remain compatible. A workflow run
does not need to be repeated because of this test-only correction.
