# v3.2.0 DiffBind and DESeq2ATAC update - 2026-08-13

> **Historical update record:** The universal multi-condition, all-sample
> consensus and built-in annotation extension of 2026-08-18 supersedes this
> page where behavior differs. See
> [Differential accessibility](13_differential_accessibility.md).

## Scope

This update changes only differential-accessibility analysis and its direct
configuration, validation, reporting, tests and documentation.

- DiffBind now defaults to `summits=100`, configurable through
  `DIFFBIND_SUMMITS`.
- DESeq2ATAC is added as an independent raw-count DESeq2 module that now runs
  separate broad- and narrow-consensus analyses.
- Existing Bash orchestration, upstream BAM/peak processing, track generation,
  QC, UCSC output and cleanup behavior are unchanged.
- The public workflow version remains 3.2.0 pending a representative server
  validation run.

## Configuration to merge

Do not overwrite a project-specific configuration. New projects should add or
review:

```bash
DIFFBIND_SUMMITS=100
RUN_DESEQ2ATAC=true
DESEQ2ATAC_MIN_SAMPLES=2
DESEQ2ATAC_ALPHA=0.05
DESEQ2ATAC_BLOCK_COLUMN=""
DESEQ2ATAC_REFERENCE_CONDITION=""
```

Set every non-control samplesheet row to `macs2_mode=both` when DESeq2ATAC is
enabled. Both peak types are required because each has its own consensus and
DESeq2 model.

Only set a block column for real donor pairing or an experimental batch that
is represented in both conditions. The module rejects a missing or confounded
block rather than fitting an invalid model.

For an existing checkpointed run, the scripts supply all values above as
defaults. Leave the project config unchanged when those defaults are desired;
changing the config changes the workflow's global run signature and makes all
old checkpoints stale. Add the variables to an existing config only when a
non-default value is required.

No HTSeq dependency was added. The module uses packages already in the

environment, preflight reports any missing package.

## Checkpoints and existing runs

DiffBind and DESeq2ATAC use independent sentinels:

```text
.checkpoints/step12.done
.checkpoints/step12a.done
```

For an existing run, broad and narrow peaks plus filtered BAMs can be reused.
Apply the code update, leave the existing config unchanged when using the defaults, and remove
only the directly affected checkpoints:

```bash
cd /home/micgdu/Analysis/run7_ATAC

rm -f /path/from_OUTPUT_DIR/.checkpoints/step12.done \
      /path/from_OUTPUT_DIR/.checkpoints/step12a.done \
      /path/from_OUTPUT_DIR/.checkpoints/step14.done

bash /home/micgdu/Analysis/workflows/ATACseq2tracks/scripts/smoke_test.sh \
    config/samplesheet.csv config/config.conf
```

If preflight passes, resume the normal entry point. Earlier completed stages
remain checkpointed. Step 12 reruns DiffBind using 201-bp windows; Step 12a
creates `deseq2atac/broad/` and `deseq2atac/narrow/`; Step 14 rebuilds the
combined report summary.

The wrapper does not delete results from the preceding single broad-analysis
layout. If `deseq2atac/deseq2atac_summary.txt` already exists, it prints a
warning; that legacy root-level result is not read by the new analysis or final
report. Archive the old `deseq2atac/` directory before resuming when a completely
unambiguous output tree is required.

## Validation performed locally

- all Bash entry points, modules and tests pass `bash -n` under Git Bash;
- entry points remain byte-identical;
- configuration templates remain byte-identical;
- focused differential-accessibility static checks pass;
- new scripts and documentation are UTF-8/LF without BOM;
- the DESeq2ATAC R source passes `parse()` with local R.

The complete Windows regression harness cannot execute locally because its
Python launcher and Bioconductor packages are unavailable. This is an
environment limitation, not a test failure in the modified code. The synthetic
DESeq2 self-test and real BAM counting must be run in the server Conda environment.

## Required server acceptance

```bash
conda activate ATACseq2tracks
cd /home/micgdu/Analysis/workflows/ATACseq2tracks

bash tests/check_bash_syntax.sh
Rscript scripts/deseq2atac_analysis.R --self-test
```

Then run representative PE and SE projects separately and confirm:

1. DiffBind summaries report `Summit half-width (bp): 100`.
2. Both broad and narrow consensus BED intervals are sorted, non-overlapping,
   canonical, blacklist-free and have support at least two.
3. Raw count matrices contain non-negative integers in samplesheet order.
4. PE counting reports fragments and SE counting reports reads.
5. Complete/significant compressed result tables pass `gzip -t`.
6. A zero-hit analysis exits successfully and retains the full result table.
7. All required PNG and PDF figures are non-empty.
8. `.checkpoints/step12.done` and `step12a.done` can be removed and resumed
   independently.
9. `reports/differential_accessibility_summary.tsv` includes DiffBind and both
   DESeq2ATAC peak types.

Compare DiffBind and both DESeq2ATAC results alongside FRiP, TSS enrichment,
replicate correlations and PCA. Broad and narrow DESeq2ATAC consensuses are
constructed separately through atomic-segment support filtering; DiffBind
additionally recenters its consensus to fixed summit windows. Exact agreement
is therefore not expected.
