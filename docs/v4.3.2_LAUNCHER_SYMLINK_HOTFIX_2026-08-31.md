# ATACseq2tracks v4.3.2 launcher symlink hotfix

## Scope

Version 4.3.2 corrects the activation-free shared launcher installed at
`/usr/local/bin/atacseq2tracks`. Scientific processing and outputs are unchanged.

## Cause

The v4.3.1 launcher derived its repository root directly from
`${BASH_SOURCE[0]}`. When invoked through the shared command symlink, that value
identified `/usr/local/bin/atacseq2tracks`; the launcher consequently attempted
to execute the nonexistent `/usr/local/atacseq2tracks.sh`.

## Correction

The launcher now resolves its physical target with `readlink -f` before deriving
the repository root. A regression test creates an external command symlink and
invokes `--version` through it, matching the shared installation topology.

Version 4.3.2 includes the v4.3.1 DESeq2ATAC synthetic self-test correction.
No analysis needs to be repeated because of this launcher-only change.
