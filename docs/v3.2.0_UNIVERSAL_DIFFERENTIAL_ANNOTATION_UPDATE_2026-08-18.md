# ATACseq2tracks 3.2.0 universal differential-analysis update

**Snapshot date:** 2026-08-18  
**Version string:** 3.2.0 (no version-number change)  
**Scope:** multi-condition differential accessibility, result summaries, and
simple GTF/cCRE peak annotation

## Implemented behavior

- Condition names and counts are unrestricted and data-driven.
- Every non-control biological sample contributes to broad and narrow consensus
  construction and the all-sample descriptive raw count matrix.
- Conditions with fewer than two biological samples are excluded only from
  statistical models and contrasts.
- DiffBind and DESeq2ATAC each fit one multi-condition model per peak type and
  export every pair among eligible conditions.
- Both differential modules restrict their final universes to canonical nuclear
  chromosomes and remove intervals overlapping the configured blacklist.
- Broad/narrow analyses continue independently; DiffBind and DESeq2ATAC remain
  peer modules.
- Comparison directories use stable indexed IDs and summaries retain the exact
  original numerator/reference condition names.
- Pair-level summaries report tested, significant, higher-in-numerator and
  higher-in-reference site counts, thresholds, status and result paths.
- A combined TSV and compact HTML table are written under `reports/`.
- Zero significant sites is successful; no eligible pair is skipped; analysis or
  export errors are failed. Reports are written before a failed run exits and
  automatic cleanup is suppressed.
- The existing selected-intermediate cleanup runs by default after full success;
  filtered quantitative BAMs remain retained and
  `ENABLE_AUTOMATIC_CLEANUP=false` disables cleanup completely.
- Two-condition root-level result names are copied for practical compatibility.

## Annotation

`RUN_SIMPLE_PEAK_ANNOTATION=true` annotates each shared peak universe once and
joins the result to all pair-level tables. The selected GTF provides promoter,
exon, intron, other-gene-body and distal-intergenic context, non-exclusive
overlap flags, nearest gene, and strand-aware signed TSS distance.

A default-required genome-matched cCRE BED adds all cCRE overlaps, a
deterministic primary overlap and enhancer-like status for pELS/dELS.
Recommended provenance:

- hg38: native ENCODE4 expanded Registry, GRCh38 (2026);
- mm39: ENCODE3 mm10 `encodeCcreCombined` lifted to mm39 using the approach in
  `MichalGd/ATAC-seq/utilitiies/creating_ENCODE_cCRES_mm39_bigBed_track.sh`.

The two species use different registry generations; class totals are not
directly comparable. Empty, missing or malformed cCRE paths fail preflight by
default. Set `RUN_CCRE_ANNOTATION=false` for an explicit GTF-only run.

`utilities/prepare_encode4_hg38_ccre.sh` prepares the human reference at the
configured default path. It uses the native GRCh38 ENCODE4 BED directly (no
liftOver), validates the complete record/class contract, and records checksums
and download provenance.

## Deliberately unchanged

- Bash architecture and stage numbering;
- trimming, alignment, deduplication, filtering, MACS3 peak calling;
- CPM and DESeq2-derived track generation/normalization;
- ATAC QC and consensus-track behavior;
- PE fragment and SE read semantics;
- module-level checkpoint architecture and the existing `KEEP_*` selectors.

The current run may be restarted from scratch. Comparison status files improve
diagnostics, but the workflow does not claim contrast-level model checkpointing:
rerunning a failed differential module refits its peak-type model.

## Required server validation

```bash
conda activate ATACseq2tracks
cd /home/micgdu/Analysis/workflows/ATACseq2tracks
bash tests/check_bash_syntax.sh

bash scripts/smoke_test.sh \
  /path/to/project/config/samplesheet.csv \
  /path/to/project/config/config.conf
```

Then run a small four-condition fixture (two biological samples per condition),
a fixture containing one singleton condition, and a two-condition compatibility
fixture. Confirm 6, 3/6 as appropriate, and 1 pair(s) per method/peak type,
respectively; verify that the singleton appears in consensus metadata but not in
model metadata.
