# v3.2.0 track-normalization update — 2026-08-06

This is a narrowly scoped cumulative update to the v3.2.0 test-run hotfix. It does not change the Bash architecture or add dependencies.

## Output contract

For every non-control biological sample, the workflow creates:

| Family | Scale applied to raw fragment/read coverage | Files |
|---|---|---|
| CPM | `1e6 / N_j`, where `N_j` is the canonical filtered fragment count for PE or read count for SE | `*_CPM.bw` |
| DESeq2 consensus | `1 / s_j` | `*_DESeq2Consensus.bw`, `*_DESeq2Consensus.bedGraph` |
| DESeq2 robust CPM | `1e6 / (s_j * G)` | `*_DESeq2RobustCPM.bw`, `*_DESeq2RobustCPM.bedGraph` |

Here, `s_j` is the DESeq2 `poscounts` size factor calculated from the shared consensus-peak matrix `K`, and `G = exp(mean(log(colSums(K))))`. The robust scale is checked directly against `DESeq2::fpm(dds, robust=TRUE)`.

No CPM bedGraph is generated. Robust CPM is the DESeq2-consensus track multiplied by the cohort-wide constant `1e6/G`; it changes the unit but not relative scaling among samples in that cohort. Neither DESeq2-derived family is an absolute cross-study calibration.

## Shared signal and genomic semantics

- PE: require proper pairs, select one first-mate alignment per fragment, and use deepTools `--extendReads` to span the insert.
- SE: `SE_SIGNAL_MODE="read"` retains read-based coverage and counting; one filtered alignment is one observation and no artificial extension is applied.
- Do not mix PE and SE libraries in one run or DESeq2 normalization cohort. Use separate samplesheets, configurations and output directories.
- Use canonical autosomes plus X/Y for hg38 or mm39 throughout consensus construction, consensus counting and track generation.
- Mitochondrial and noncanonical contigs are excluded; blacklist regions have already been removed from the filtered BAMs.
- `TRACK_STANDARD_CHROMS_ONLY=true` is required by this output contract.

The existing SE MACS3 parameters (`MACS3_ATAC_SE_SHIFT` and `MACS3_ATAC_SE_EXTSIZE`) are used only for peak calling. They do not alter SE coverage or consensus-count semantics. A future Tn5 mode would require explicit strand-aware cut-site conversion and is not implemented here.

## Metadata

`qc_post_alignment/tables/consensus_sizeFactors.tsv` records the DESeq2 factor, consensus matrix column sum, cohort geometric mean, robust effective library size and both DESeq2-derived scales.

`qc_post_alignment/tables/track_normalization_metadata.tsv` records, for every sample, the signal unit, CPM normalization count, consensus count sum, cohort constant and applied scales. Step 7 also writes `bigwig/*_CPM.metadata.tsv` beside each CPM bigWig.

## Applying to an existing v3.2.0 analysis

Back up the installed workflow, overlay the updated files, then run:

```bash
cd /path/to/ATACseq2tracks
bash tests/check_bash_syntax.sh
bash scripts/smoke_test.sh /path/to/samplesheet.csv /path/to/config.conf
```

The version remains 3.2.0, so script changes alone do not alter the existing checkpoint signature. Remove the directly affected stage checkpoints before resuming:

```bash
rm -f /path/to/output/.checkpoints/step7.done \
      /path/to/output/.checkpoints/step8.done \
      /path/to/output/.checkpoints/step10.done \
      /path/to/output/.checkpoints/step13.done \
      /path/to/output/.checkpoints/step14.done

bash /path/to/ATACseq2tracks/atacseq2tracks.sh \
  --config /path/to/config.conf
```

Steps 1–6 and 9 remain checkpoint-resumable. Existing filtered BAMs, peaks, differential-analysis inputs and other unrelated outputs are not deleted. Old `*_RPM.bw` files are not renamed or removed automatically; archive them to avoid confusing them with the new `*_CPM.bw` contract.

## Acceptance checks

The focused regression suite checks PE and SE execution, read/fragment denominators, rejection of unsupported SE modes and mixed-layout samplesheets, canonical peak filtering, the robust scaling identity, output names, the absence of CPM bedGraphs, non-empty mocked outputs, and retention of checkpoint/skip logic. Representative PE-only and SE-only server runs should additionally confirm that all five requested DESeq2/CPM files per sample are non-empty and inspect several loci in a genome browser.

Cross-study comparisons still require harmonized processing and, for absolute calibration under global accessibility shifts, spike-in or another external reference.
