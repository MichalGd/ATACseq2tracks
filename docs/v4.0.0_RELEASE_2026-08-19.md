# ATACseq2tracks 4.0.0 release

Date: 2026-08-19

Version 4.0.0 consolidates the prepared multi-condition, annotation,
normalization and correctness updates and accelerates later BAM-intensive
stages without changing track contents, BedGraph placement, biological models,
workflow architecture or checkpoint names.

## Default configurable limits

```bash
QC_SAMPLE_PARALLEL_JOBS=4
ATAQV_PARALLEL_JOBS=4
TRACK_PARALLEL_JOBS=2
POOLED_MACS_PARALLEL_JOBS=2
MERGE_PARALLEL_JOBS=2
```

These values are defaults, not fixed constants. Existing run configurations
that do not contain them receive the same defaults from the scripts. Add them to
a run configuration only when an override is needed. Per-process thread limits
remain controlled by `THREADS_DEEPTOOLS`, `THREADS_ATAQV`, `THREADS_BIGWIG` and
`THREADS_SAMTOOLS`.

## Parallelized work

- Post-alignment per-sample metrics, karyograms and consensus FRiP are bounded
  by `QC_SAMPLE_PARALLEL_JOBS`.
- ataqv, selected-metric extraction and PE periodicity plotting run as one
  sample job, bounded by `ATAQV_PARALLEL_JOBS`. `mkarv` runs after all jobs.
- Each sample's four DESeq2-derived tracks remain internally sequential, while
  up to `TRACK_PARALLEL_JOBS` samples run concurrently.
- Per-replicate MACS3 retains its existing pool; pooled group calls now use
  `POOLED_MACS_PARALLEL_JOBS`.
- Replicate merging, indexing and merged CPM generation use
  `MERGE_PARALLEL_JOBS`.

DiffBind and DESeq2ATAC broad/narrow modules remain sequential because their R
backends can consume substantial memory and may create their own workers.

## Safety and reproducibility

Workers never append concurrently to final summary tables. They write unique
temporary rows, which are joined in samplesheet order. Required worker failures
are collected and cause the parent stage to exit non-zero. Existing output-skip
and checkpoint behavior is retained.

Timing tables make server tuning measurable:

- `qc_post_alignment/tables/parallel_job_timing.tsv`;
- `qc_post_alignment/atac_qc/tables/ataqv_job_timing.tsv`;
- `peaks/macs3_job_timing.tsv`;
- `bigwig_merged/merge_job_timing.tsv`.

## Resume behavior

Installing this hotfix does not require restarting an existing analysis.
Completed checkpoints remain valid when the run-specific config and samplesheet
are left unchanged. The faster code is used for incomplete or deliberately
rerun stages and for future analyses. Do not replace a run-specific config with
the repository template; add only desired overrides.

## Validation

Run:

```bash
bash tests/check_bash_syntax.sh
```

The focused pool tests verify positive job limits, failure propagation,
deterministic merging, timing rows, mocked replicate merging and mocked
per-replicate/pooled MACS3 execution. Full post-alignment and ataqv performance
must still be benchmarked on representative server BAM files because storage
throughput cannot be simulated meaningfully in the static test suite.
