# ATACseq2tracks 3.2.0 IRanges namespace hotfix

**Snapshot date:** 2026-08-19

**Version string:** 3.2.0

**Scope:** fatal overlap-generic namespace correction only

## Failure corrected

The first universal multi-condition production run completed upstream Steps
1--11 but both broad/narrow DiffBind analyses and both broad/narrow DESeq2ATAC
analyses stopped with:

```text
'overlapsAny' is not an exported object from 'namespace:GenomicRanges'
```

`overlapsAny()` and `findOverlaps()` are IRanges generics with methods that
dispatch on `GRanges`. The affected workflow code now calls
`IRanges::overlapsAny()` and `IRanges::findOverlaps()` explicitly.

No trimming, alignment, deduplication, filtering, peak calling, normalization,

## Validation

Run after installing the hotfix:

```bash
bash tests/check_bash_syntax.sh
bash tests/test_differential_accessibility.sh

Rscript -e '
stopifnot(requireNamespace("IRanges", quietly=TRUE))
exports <- getNamespaceExports("IRanges")
stopifnot(all(c("overlapsAny", "findOverlaps") %in% exports))
cat("IRanges namespace checks: OK\n")
'
```

The differential regression test runs a functional GRanges overlap-dispatch
test when the necessary Bioconductor packages are installed. The normal
`scripts/smoke_test.sh` preflight also requires IRanges and both exported
generics.

## Resume after the failed production run

Install the corrected files over the same active workflow directory and keep
the existing run config, samplesheet and `VERSION` unchanged. The run signature
therefore remains compatible. Remove only failed downstream checkpoints if
present and launch the same command. Steps 1--11 and 13 remain reusable; Steps
12, 12a and 14 rerun.

The failed differential result directories may be renamed before resuming to
retain their diagnostics and prevent stale failure summaries from being mixed
with corrected results. Upstream BAM, peak, QC and track outputs do not need to
be regenerated.
