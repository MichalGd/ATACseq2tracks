## Slide 3

DNAfastqBigWig_human_main_v5_30aug2025.sh 
usage

# 1
PATH_to_Script/DNAfastqBigWig_human_main_v5_31aug2025.sh [inputFolder] [outputFolder] [max jobs]

[inputFolder] - folder with fastq files; seperately human and mouse; distinct scripts for each
[outputFolder] - for all script outputs
[max jobs] - maximal number of jobs to be run in parallel

#2
script assumes that one sample is represented by 1 pair of fastq files stored in seperate files in "inputFolder" named:
path/to/folder/inputFolder/*_1.fq.gz
path/to/folder/inputFolder/*_2.fq.gz
It has been tested initially on 150 bp paire-end reads generated by Illumina NovaSeqX Plu

## Slide 5

DNAfastqBigWig_human_main_v5_30aug2025.sh 
Workflow steps

1. Creating folders:
2. Quality control of unprocessed fastq files :
3. trimming fastq files with TrmmGalore based on quality & sequence - adpater removal
4. Quality control of trimmed fastq files :
5. Alignment of trimmed fastq files with Bowtie2 to hg38 genome
6. Removal of read duplicates with picard
7. Generation of coverages, rpm normalization and generation of bedGraph & bigWig files
8. Creating generic UCSC bigwig track lines
9. Generating analysis report
10. Generating report with summary of multiqc analysis of fastq files, trimming, aligmnet and deduplication
